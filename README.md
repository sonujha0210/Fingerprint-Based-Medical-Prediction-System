# 🧠 Fingerprint-Based Medical Prediction System

## 📌 Overview
This project is an AI-based medical prediction system that uses fingerprint authentication as a unique identifier to access and analyze user data. Once a user is identified, the system predicts blood group and potential eye diseases using machine learning models.

The system combines biometric security with intelligent healthcare prediction through an interactive GUI.

---

## 🧠 Key Idea
- Fingerprint → User Identification  
- Backend → Data Processing  
- ML Models → Prediction  

---

## ⚙️ Features
- 🔐 Fingerprint-based user authentication  
- 🧪 Blood group prediction  
- 👁️ Eye disease prediction  
- 🤖 Machine learning model integration  
- 💻 Interactive GUI for easy usage  

---

## 🛠️ Tech Stack
- Python  
- Machine Learning  
- NLP / Data Processing  
- Flask (for GUI/backend)
